## 🚀 Project Deployment & Infrastructure

The Booi Technologies website was developed using React and deployed using modern web development tools and services.

- **Frontend hosting:** Netlify — used to deploy and host the live website.
- **Domain management:** GoDaddy — used to manage the website's custom domain name.
- **Source code management:** GitHub — used to store the project's source code in a remote repository, track changes, and maintain version history.
- **Version control:** Git — used to manage code changes and support the development workflow.

This setup separates the source code, website hosting, and domain management, making the website easier to maintain and update.
