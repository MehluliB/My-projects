## Getting Started

Follow these steps to run a project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate into the repository:

   ```bash
   cd <repository-folder>
   ```

3. Navigate into the folder of the project you want to run:

   ```bash
   cd <project-folder>
   ```

4. Install the dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

   If the project was created using Create React App, use `npm start` instead.
